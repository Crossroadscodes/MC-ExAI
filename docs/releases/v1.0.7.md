# ExAI v1.0.7

## 更新内容 / Changes

- 新增 RAG 评估、知识语义 ID、独立测试集管理和 GUI + 聊天栏标注。
- 测试集按 YAML / MySQL 模式分别保存，支持评估报告和游戏内指标摘要。
- 优化问题判断、拒答和冷却逻辑，避免 GUI 提问被公屏重复处理。
- 优化 Web CLI：失败过程保存、流式输出滚动控制、复用工具执行状态区域。
- 提取可复用工具运行接口，增加经过身份验证的 HTTP 工具 API。
- 同步精简后的中英文 README，版本号更新为 1.0.7。

- Added RAG evaluation, semantic knowledge IDs, a dedicated test-set GUI, and chat-based annotation.
- Separated YAML/MySQL test-set storage, with evaluation reports and in-game metric summaries.
- Improved question classification, refusal and cooldown handling, and prevented duplicate public-chat processing of GUI questions.
- Improved Web CLI failure-history persistence, streaming scroll behavior, and reusable tool-status display.
- Added a reusable tool runtime and authenticated HTTP tool APIs.
- Updated the English README to match the revised Chinese documentation and bumped the version to 1.0.7.
